# BioRegisto

BioRegisto is a software application developed as part of a Bachelor's degree
project in Computer Engineering at ESTG-IPVC.

The project was developed in collaboration with another student and aims to
support the management and registration of information within CMIA
(Centro de Monitorização e Investigação Ambiental) context.

## Project Overview

BioRegisto consists of a mobile application for citizens and a desktop
backoffice for administrative and technical users.

The system uses a REST API to connect the applications to a PostgreSQL
database, allowing information to be managed and shared between the
different components.

## Main Features

- Citizen mobile application
- Desktop backoffice for technical and administrative users
- User authentication and role-based access
- Registration and management of observations
- Communication between applications through a REST API
- Data persistence using PostgreSQL

## Technologies

- Flutter
- C#
- ASP.NET Core
- Entity Framework Core
- PostgreSQL
- REST API
- Git

## Architecture

The project is divided into three main components:

- **Citizen App** – mobile application developed with Flutter
- **Backoffice** – desktop application for technical and administrative users
- **Backend API** – ASP.NET Core Web API responsible for communication
  between the applications and the database
